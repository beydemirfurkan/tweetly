# Icerik Stratejisi

## Hedef Kitle
- Turkce yazilimcilar
- AI tool kullanan founder'lar ve indie hacker'lar
- Coding assistant kullanan gelistiriciler
- Open source takipçileri

## Pozisyonlama
"Her gun ise yarayan AI/dev tool'lari kisa, pratik ve Turkce anlatan hesap."

## Icerik Prensipleri

### Genel Kurallar
1. Ana tweet cogu zaman linksiz olmali
2. Link reply'da verilmeli
3. Her post tek amac tasinmali: reply, bookmark, profile click, retweet veya link click
4. Tekrar ayni cumle kalibindan kacinilmali
5. "Bu repo sunu yapiyor" yerine "bunu hangi problemde kullanirsin?" yaklasimi
6. Emoji ve hashtag kullanilmamali
7. Pazarlama dilinden kacinilmali
8. Teknik terimler Ingilizce kalabilir

### Algoritmaya Gore Onceliklendirme
| Oncelik | Sinyal | Nasil |
|---------|--------|-------|
| 1 | Reply | Soru sor, fikir iste, karsilastirma yap |
| 2 | Profile click | Bio'yu guclendirmek, CTA eklemek |
| 3 | Dwell | Mini thread, detayli aciklama |
| 4 | Bookmark | Liste, derleme, "sonra bak" formati |
| 5 | Retweet | Faydali kaynak paketi, karsilastirma |
| 6 | Link click | Reply'da kaynak linki |

## Format Detaylari

### repo_drop
**Amac:** Fayda
**Yapi:** Kisa repo aciklamasi + link etiketi
**Ornek:**
```
ai coding agent'lar icin hafiza ve context yonetim katmani.

repo: https://github.com/example/agent-memory
```
**Kullanilma:** Kisa, dogrudan, gunluk 1-2 tane

### no_link_hook
**Amac:** Reach
**Yapi:** Problem/gozlem, link yok
**Ornek:**
```
ai coding agent'larin en zayif tarafi cogu zaman kod degil, urun hissi.

bu repo, agent ciktisini daha iyi UI kararlarilte yonlendirmek icin kullanilabilecek pratik bir skill set gibi duruyor.
```
**Kullanilma:** Sabah ve aksam, gunluk 2 tane

### question
**Amac:** Reply
**Yapi:** Kullanicinin fikrini soran yapi
**Ornek:**
```
cursor'da custom mode kullanan var mi? yoksa her seyi agent moduna birakiyor musunuz?

son bir haftadir iki yaklasimi da denedim, sonuclar oldukca farkli.
```
**Kullanilma:** Gunluk 1 tane

### comparison
**Amac:** Tartisma, retweet
**Yapi:** X yerine neden Y tartismasi
**Ornek:**
```
windsurf ve cursor arasinda kalanlar icin: ikisi de ayni is yapiyor ama farkli felsefelerle.

biri context agirlikli, oburu tool call agirlikli calisiyor.
```
**Kullanilma:** Gunluk 1 tane

### mini_thread
**Amac:** Dwell
**Yapi:** 3 tweet - sorun, cozum, senaryo
**Ornek:**
```
1/ ai agent kurarken en zor kisim cogu zaman model secimi degil.

asils sorun: dosya yapisi, tool cagrilari, hafiza ve hata toparlama akisini temiz kurmak.
```
```
2/ bu repo, agent workflow'unu daha moduler kurmak isteyenler icin iyi bir referans olabilir.

ozellikle kendi internal dev tool'unu yazan ekiplerin isine yarar.
```
```
3/ repo:
https://github.com/example/repo
```
**Kullanilma:** Gunluk 1 thread (3 tweet)

### bookmark_bait
**Amac:** Bookmark
**Yapi:** Liste veya derleme
**Ornek:**
```
bu hafta dikkatimi ceken 5 ai coding tool'u:

1. codex - openai'nin coding agent'i
2. devika - open source coding assistant
3. aider - terminal tabanli ai pair programmer
4. continue - ide eklentisi
5. cursor - ai-first code editor
```
Reply:
```
linkler:
1. https://github.com/...
2. https://github.com/...
...
```
**Kullanilma:** Haftalik 1-2 tane

### hot_take
**Amac:** Reply
**Yapi:** Yumusak gorus belirtme
**Ornek:**
```
ai coding'de asil fark model degil, context yonetimi.

hangini modeli kullanirsan kullan, dogru dosyalari dogru sirayla veremezsen sonuclar ortada.
```
**Kullanilma:** Gunluk 1 tane

### weekly_digest
**Amac:** Bookmark, retweet
**Yapi:** Haftanin onemli repolari
**Ornek:**
```
bu haftanin onemli 7 reposu:

1. openai/codex - terminal tabanli coding agent
2. browser-use/browser-use - web browser kontrolu
3. ...
7. ...

ayrintilar icin thread'e bakin.
```
**Kullanilma:** Her Cuma 1 tane

### sponsor_native
**Amac:** Para, click
**Yapi:** Dogal dilde sponsor icerik
**Ornek:**
```
[urun] ile [sorun] cozmek oldukca kolaylasiyor.

ozellikle [ozellik] kismi diger alternatiflerden ayriliyor.

(sponsorlu)
```
**Kullanilma:** En fazla haftalik 1 tane
